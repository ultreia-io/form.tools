# Contributing

Open an issue describing the proposed contract or behaviour change, with a small synthetic reproduction.

Develop on `develop`. Use `feature/` branches only when requested.

Submit pull requests to `develop` and assign Tony Chemit (`ultreiaio`).

Keep runtime dependencies minimal. Tests and examples must work offline without credentials or domain data.

Edit YAML artifacts once. Edit `README.md` directly.

Edit roxygen comments, then regenerate and commit `man/*.Rd` and `NAMESPACE`.

Run the commands in [DEVELOPMENT.md](DEVELOPMENT.md) before requesting review.

Explain proposed regression tests and obtain approval before adding them. Describe compatibility changes in NEWS.

By contributing, you agree to license your contributions under LGPL-2.1.
